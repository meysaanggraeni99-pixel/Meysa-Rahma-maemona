🔧 AKTIVITAS 8

Debugging

let harga = 5000;
let jumlah = 3;
let total harga = harga * jumlah;

console.log(total harga);
Kesalahan:

Nama variable total harga menggunakan spasi. Nama variable tidak boleh menggunakan spasi.

Perbaikan kode: 
let harga = 5000;
let jumlah = 3;

let totalHarga = harga * jumlah;

console.log(totalHarga);
Hasil = 15000

📚 BAHAN AJAR

Mengingat Variable

Variable adalah tempat untuk menyimpan data. 

let nama = "Budi";
let umur = 17;
let nilai = 85;

Input – Process – Output

INPUT
↓
PROCESS
↓
OUTPUT

let harga = 5000;
let jumlah = 3;
let total = harga * jumlah;

console.log(total);

Output dengan console.log()

console.log("Halo");

let nama = "Budi";

console.log(nama);

console.log("Nama saya adalah", nama);

Input dengan prompt()

let nama = prompt("Masukkan nama:");

console.log(nama);

Alur: Pengguna mengetik → prompt() → variable → console.log().

Operator Aritmatika

Operator Fungsi Contoh Hasil
+ Penjumlahan 10 + 5 15
- Pengurangan 10 - 5 5
* Perkalian 10 * 5 50
/ Pembagian 10 / 5 2
% Sisa pembagian 10 % 3 1

Variable dalam Perhitungan

let nilai1 = 80;
let nilai2 = 90;

let total = nilai1 + nilai2;

console.log(total);

Contoh Kehidupan Nyata

Harga satu buku Rp10.000 dan membeli 3 buku. 

let harga = 10000;
let jumlah = 3;

let total = harga * jumlah;

console.log(total);

Hasilnya 30000.

Pola Dasar Program

let data1 = ...;
let data2 = ...;

let hasil = data1 OPERASI data2;

console.log(hasil);

let panjang = 10;
let lebar = 5;

let luas = panjang * lebar;

console.log(luas);

Catatan tentang prompt()

Hasil prompt() secara umum diterima sebagai teks/string. Untuk mengubahnya menjadi angka dapat digunakan Number(). 

let angka = Number(prompt("Masukkan angka:"));
